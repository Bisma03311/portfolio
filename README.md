# Bisma Ahmad — Portfolio

Portfolio of Bisma Ahmad, an AI Engineer trainee, graphic and logo designer, and content writer combining technology, creativity, and marketing.

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- React
- TypeScript
- Tailwind CSS
- Motion

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

`npm run build`
